Crie um projeto Python completo chamado "agente_clinica_manustetic" 
para uma clínica estética chamada Manustetic.

## ESTRUTURA DE ARQUIVOS:
agente_clinica_manustetic/
├── .env.example

## TECNOLOGIAS:
- Framework: Agno
- Modelo: Groq (primary: openai/gpt-oss-120b, fallback: llama-3.3-70b-versatile)
- Banco de dados: DuckDB local (arquivo appointments.db na raiz do projeto)
- Interface: Streamlit
- Idioma: Português do Brasil (pt-BR)

## REGRAS DE NEGÓCIO:
- Horário de funcionamento: Segunda a Sábado, 08:00 às 19:00
- Fechado aos domingos
- Formato de data: dd-mm-yyyy HH:MM (24h)
- Duração padrão de cada procedimento: 1 hora
- Limite de sessão: 15 mensagens

## BANCO DE DADOS DUCKDB:
- Arquivo: appointments.db
- Criar função init_db() que inicializa a tabela se não existir
- Fazer migration automática se colunas novas forem adicionadas
- Estrutura da tabela appointments:
  id VARCHAR,
  customer_name VARCHAR,
  appointment_time TIMESTAMP,
  service VARCHAR,
  status VARCHAR DEFAULT 'scheduled',
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP

## FERRAMENTAS QUE O AGENTE DEVE TER (functions/tools):

1. schedule_appointment(customer_name, appointment_time, service)
   - Conectar no DuckDB e verificar se já existe agendamento
     no mesmo horário com status 'scheduled' ou 'rescheduled'
   - Se ocupado: retornar mensagem de conflito 
     + buscar e sugerir os 3 próximos horários livres do dia
   - Se livre: inserir no DuckDB e retornar ID no formato
     APPT-{timestamp}

2. reschedule_appointment(appointment_id, new_time)
   - Verificar se appointment_id existe no DuckDB
   - Verificar se o novo horário está livre
   - Se ocupado: sugerir 3 próximos horários livres
   - Se livre: UPDATE no DuckDB com novo horário
     e status = 'rescheduled'

3. cancel_appointment(appointment_id)
   - Verificar se appointment_id existe
   - UPDATE status = 'cancelled' no DuckDB
   - Retornar confirmação

4. get_upcoming_appointments(customer_name)
   - SELECT no DuckDB filtrando por customer_name,
     status IN ('scheduled','rescheduled')
     e appointment_time > CURRENT_TIMESTAMP
   - Retornar lista formatada em pt-BR

5. suggest_free_slots(date)
   - Buscar no DuckDB todos horários ocupados na data
   - Calcular horários livres entre 08:00 e 19:00
     considerando 1 hora por procedimento
   - Retornar lista de horários disponíveis
